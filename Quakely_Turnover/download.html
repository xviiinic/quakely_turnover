Thank you for taking part in the evaluation of Quakely, an Android-based educational mobile game designed to introduce Grade 4–6 learners to earthquake preparedness through interactive, localized, and scenario-based activities. Please follow the instructions below to download, install, and launch the evaluation build on your Android device.

This version of Quakely is a pre-release evaluation build developed for the project's system evaluation phase. The application is being evaluated for selected software quality characteristics and its instructional suitability for the intended educational context.

As an evaluation build, you may encounter minor bugs, visual inconsistencies, performance issues, or other unfinished elements during gameplay.

Your feedback and evaluation are important in identifying areas for improvement.

INSTALLATION GUIDE

  1. Step 1 — Download the APK Tap Download Quakely APK and wait for the APK file to finish downloading.
  2. Step 2 — Allow Installation Open the downloaded APK file. If your device displays a security message, open Settings and allow your browser or file manager to Install unknown apps / Allow from this source. (The exact wording may vary depending on your Android device.)
  3. Step 3 — Install Quakely Return to the downloaded APK, tap it, and select Install.
  4. Step 4 — Launch the Game Tap Open to launch Quakely and follow the on-screen instructions.
  5. Step 5 — Start Playing Explore Quakely's different learning modules and interactive activities to familiarize yourself with the application.

System Evaluation Guidelines

This is a pre-release evaluation build of Quakely developed for the project's system evaluation phase.

Please Note

  • Evaluation Build: This is not the final public release of Quakely.
  • Purpose: The application is provided for system evaluation and academic research purposes.
  • Gameplay: Quakely's core learning activities can be played offline.
  • Internet Connection: An internet connection may be required for certain monitoring and synchronization functions.
  • Target Platform: Quakely is currently developed for Android devices.

Privacy & Data Policy

Gameplay Data

Quakely records selected gameplay information using a system-generated Learner Monitoring ID for gameplay observation and system verification. It is not used for grading or academic assessment.

Evaluation Data

Information provided through evaluation forms will be used for academic research and system evaluation and handled confidentially.

Data Protection

Collected data will not be sold or used for commercial purposes and will be managed according to the project's research procedures.

Quakely Release Notes

Android System Requirements

Minimum & Recommended Requirements

Requirement Minimum / Recommended
Operating System Android 10 or higher
RAM 2 GB minimum; 4 GB recommended
Storage 32 GB minimum device storage
Display / Input Multi-touch touchscreen
Internet Connection Not required for core learning activities
Connectivity Internet may be used for Firebase synchronization and monitoring functions
The application is developed exclusively for Android devices. Core learning activities are designed to function offline, while Firebase integration is used for cloud synchronization and monitoring functions when connectivity is available.
